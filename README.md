# 📱 AnotaAí

O **AnotaAí** nasceu como um experimento pessoal: passar um dia sendo um **Vibe Coder** e descobrir até onde seria possível chegar desenvolvendo uma ideia com a ajuda da inteligência artificial.

A proposta foi começar com uma necessidade simples e transformar a ideia, aos poucos, em um sistema funcional para organização de pequenos negócios.

## 🤖 O que é Vibe Coding?

Vibe Coding é uma forma de desenvolver na qual a pessoa descreve o que deseja, testa o resultado e aprimora o projeto com a ajuda da inteligência artificial.

Este projeto não foi criado para demonstrar domínio avançado de programação. Ele representa um processo de aprendizado, experimentação e construção colaborativa com IA.

## 🚀 Sobre o AnotaAí

O AnotaAí é um sistema pensado para ajudar pequenos vendedores e prestadores de serviços a organizar suas atividades de maneira simples.

Entre suas funcionalidades estão:

* Cadastro de clientes e produtos;
* Registro de vendas e pagamentos;
* Controle de parcelas e vencimentos;
* Identificação de clientes com pagamentos pendentes;
* Envio de cobranças pelo WhatsApp;
* Controle de estoque;
* Relatórios e exportação em PDF;
* Backup e sincronização de dados;
* Acesso pelo celular e computador;
* Instalação como aplicativo PWA;
* Sistema de licenças e painel administrativo;
* Funcionamento offline com armazenamento local.

## 🛠️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* LocalStorage
* PWA — Progressive Web App
* PHP
* Armazenamento de backups na hospedagem
* GitHub Pages

## 💡 Objetivo do projeto

O principal objetivo foi aprender fazendo.

Durante o desenvolvimento, cada nova necessidade virou uma funcionalidade, cada erro virou um teste e cada melhoria ajudou a transformar uma ideia simples em um projeto muito maior do que o planejado inicialmente.

Este repositório representa o resultado de um dia explorando o conceito de Vibe Coding — mostrando que, com curiosidade, testes e boas ferramentas, uma ideia pode sair do papel mesmo quando você ainda está aprendendo programação.
